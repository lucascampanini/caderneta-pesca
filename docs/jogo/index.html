PESCA PANTANEIRA

Baseado no TIDELINE (BridgeMind, licença MIT) · Three.js

Como jogar

  • Mirar: mova o mouse (ou o dedo) para escolher a direção do arremesso.
  • Arremessar: segure o clique ou a barra de espaço para carregar a força e solte. Arremessos longos chegam à água funda, onde vivem os peixes raros.
  • Esperar: olhe a boia. Beliscadas pequenas são só o peixe experimentando; quando ela afunda e aparece o !, você tem uma fração de segundo.
  • Fisgar: clique (ou espaço) na hora do ! para cravar o anzol.
  • Recolher: segure o clique para puxar. Puxar aumenta a tensão; solte para aliviar. Quando o peixe dá uma arrancada, pare de puxar ou a linha arrebenta!
  • Evoluir: venda os peixes na Loja (B), troque vara, molinete, linha e isca, e libere novos pesqueiros no Mapa (M). O dourado é solto: captura proibida em MS.
  • Colecionar: cada espécie que você pega entra no Diário (J). O horário e o lugar mudam o que morde.
  • Recolher: segure o clique enquanto espera (ou aperte R) para trazer a boia de volta.
