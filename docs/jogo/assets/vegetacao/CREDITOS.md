# Créditos da vegetação

Todos os modelos e texturas de origem são **CC0 (domínio público)** da [Poly Haven](https://polyhaven.com).
Os atlas de impostor (`*.webp` + `*_n.webp`) foram renderizados no Blender 4.5 (Cycles) a partir deles.

`vegetacao.json`: para cada espécie, o arquivo de cor (com alfa), o de normais (espaço de câmera do quadro,
meia resolução), o número de ângulos (colunas), o tamanho do atlas em pixels e, por variante (linhas, de baixo
para cima), a largura e a altura em metros, a base (posição do chão no quadro, 0 = embaixo) e o tamanho do quadro.
